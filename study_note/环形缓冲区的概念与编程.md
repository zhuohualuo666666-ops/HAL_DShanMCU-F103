<!-- 环形缓冲区的概念与编程 -->

1.环形缓冲区：
本质上是一个一维数组。

2.环形缓冲区的读写：
读是取出1个数据，
写是放入一个数据。

3.使用方法：
定义
一个环形缓冲区buf[8]，
写指针w，
读指针r，
写指针下一个位置next_w。

表示环形缓冲区空：r==w
表示环形缓冲区满：next_w==r
写方法：
if(next_w!=r) //表示未满
{
    buf[w]=val;//写数据
    w++;
    if(w==8)//指针溢出
    {
    w=0;
    }
}

读方法：
if(r!=w)
{
    val=buf[r];
    r++;
    if(r==8)
    {
        r=0;
    }
}


4.next_w引入的必要性：
在一个位置写入数据后，写指针会指向下一个数据，比如在0位置写A，写指针会指向1位置。
假如不牺牲7位置，强行写入一个数据，那么根据环形buffer原理和我们编写的规则，写指针会移动至位置0。
假如此时没有读数据，读指针指向0，这个情况下buffer确实是满了，但分不清满和空。
因此牺牲一个位，引出下一位的概念，只要下一位等于读位置就是满。

本质上是通过牺牲一个小区域营造差1个位置的现象表示满，与重合的现象表示空做区分。
