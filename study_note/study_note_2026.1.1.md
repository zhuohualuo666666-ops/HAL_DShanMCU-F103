枚举是一种用户自定义的数据类型，用于定义一组具有名字的整数常量
基本语法：
typedef enum {
  标识符1 = 值1,
  标识符2 = 值2,
  ...
} 类型名;

例：
typedef enum
{
  GPIO_PIN_RESET = 0u,  // 值为0，u表示无符号
  GPIO_PIN_SET          // 值为1（自动递增1）
} GPIO_PinState;

枚举具有自动递增特性
递增规则：
1第一个值未指定时：默认为0
2后面的值未指定时：自动为前一个值+1
3可以显式赋值，然后从该值继续递增
如：
enum Colors {
    RED = 10,    // 10
    GREEN,       // 11
    BLUE = 20,   // 20
    YELLOW,      // 21
    WHITE        // 22
};
