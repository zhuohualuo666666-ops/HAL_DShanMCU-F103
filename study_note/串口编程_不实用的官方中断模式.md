一.发送函数：
1.HAL_UART_Transmit_IT（串口发送函数）内部实现的功能：
（1）使能了TXE中断
（2）需要发送多少字节，会产生多少次TXE中断
（3）发生一次TC中断


以下为该函数内部部分代码：

/* Enable the UART Transmit data register empty Interrupt */
 __HAL_UART_ENABLE_IT(huart, UART_IT_TXE);
使能TXE中断


中断处理函数中HAL_UART_IRQHandler里发送部分如下：
  /* UART in mode Transmitter ------------------------------------------------*/
  if (((isrflags & USART_SR_TXE) != RESET) && ((cr1its & USART_CR1_TXEIE) != RESET))
  {
    UART_Transmit_IT(huart);
    return;
  }

  /* UART in mode Transmitter end --------------------------------------------*/
  if (((isrflags & USART_SR_TC) != RESET) && ((cr1its & USART_CR1_TCIE) != RESET))
  {
    UART_EndTransmit_IT(huart);
    return;
  }

TXE中断标志位挂起，调用UART_Transmit_IT函数，
TC中断标志位挂起，调用 UART_EndTransmit_IT函数


UART_Transmit_IT函数中，当数据发送完毕，会禁止TXE中断，使能TC中断：
 if (--huart->TxXferCount == 0U)     //发送到最后一个数据
    {
      /* Disable the UART Transmit Data Register Empty Interrupt */
      __HAL_UART_DISABLE_IT(huart, UART_IT_TXE);

      /* Enable the UART Transmit Complete Interrupt */
      __HAL_UART_ENABLE_IT(huart, UART_IT_TC);
    }


UART_EndTransmit_IT函数中，清除了中断标志位，调用中断回调函数
  /*Call legacy weak Tx complete callback*/
  HAL_UART_TxCpltCallback(huart);

2.官方中断方式发送函数编程思路：
定义一个全局变量g_tx_cplt表示状态，初始为0，表示未发送完成；
编写自己的回调函数HAL_UART_TxCpltCallback，在其中将g_tx_cplt置为1；
定义一个函数Wait_Tx_Complete，在其中用while循环g_tx_cplt等于0阻塞，出阻塞后表示发送完成，再置为0；
具体如下：
static volatile int g_tx_cplt = 0;
void HAL_UART_TxCpltCallback(UART_HandleTypeDef *huart)
{
	g_tx_cplt = 1;
}

void Wait_Tx_Complete(void)
{
	while (g_tx_cplt == 0);
	g_tx_cplt = 0;
}



二、接收函数（不实用）：
HAL_UART_Receive_IT函数内部实现的功能：
返回UART_Start_Receive_IT，
该函数内部使能RXNE中断：
__HAL_UART_ENABLE_IT(huart, UART_IT_RXNE);

中断处理函数中HAL_UART_IRQHandler里接收部分如下：
  /* UART in mode Receiver -------------------------------------------------*/
    if (((isrflags & USART_SR_RXNE) != RESET) && ((cr1its & USART_CR1_RXNEIE) != RESET))
    {
      UART_Receive_IT(huart);
      return;
    }

RXNE中断标志位挂起，调用UART_Receive_IT函数，内部部分如下：
  /* Disable the UART Data Register not empty Interrupt */
      __HAL_UART_DISABLE_IT(huart, UART_IT_RXNE);
接收完关RXNE中断,调用回调函数HAL_UART_RxCpltCallback。
