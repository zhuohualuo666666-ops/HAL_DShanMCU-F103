利用点阵字库生成工具，点阵格式选择阴码模式（1点亮），取模走向选择逆向（低位在前），取模方式选择列行式，
生成汉字点阵，该点阵分为两行，分别表示一个汉字的上半和下半两部分，每一部分从左到右排列，包含16个字节，
每个字节表示一列8位。

显示汉字函数如下：
void OLED_PrintChinese(uint8_t x, uint8_t y)
{   
	extern uint8_t g_chinese_fonts[3][32];//声明数组

	uint8_t page = y;
	uint8_t col  = x*8;
	
	if (y > 7 || x > 15)//超出页和列宽度
			return;
	
	int i;
	for (i = 0; i < sizeof(g_chinese_fonts)/sizeof(g_chinese_fonts[0]); i++) //循环范围是整个数组大小除以数组里第一项的大小，算出具体有多少个汉字
	{
		/* 设置位置: page,col */
    OLED_SetPosition(page, col);

		/* 发送16字节数据(汉字的上半部) */
    OLED_WriteNBytes((uint8_t*)&g_chinese_fonts[i][0], 16);

		/* 设置位置: page+1,col */
    OLED_SetPosition(page+1, col); //下一页继续发送下半部分
		
		/* 发送16字节数据(汉字的下半部) */
    OLED_WriteNBytes((uint8_t*)&g_chinese_fonts[i][16], 16);

		/* 更新下一个字符的位置:page不变,col+=16 */	
		col += 16; //一个汉字占16列的宽度
	}
}
